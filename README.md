# Busy Dad Tracker PWA

Installable Pixel 9 PWA for Busy Dad-style training.

## Features

- 6-count military burpee tracker
- Navy Seal burpee tracker
- Walk logging
- 20-minute landmark workout standard
- Busy Dad level progression
- Manual rep buttons
- Voice-assisted counting
- Local browser storage
- Offline app shell via service worker
- Pixel/Android install support via manifest.json

## Run locally

```bash
npm install
npm run dev
```

Open the local URL in Chrome.

## Build

```bash
npm run build
npm run preview
```

## Install on Pixel 9

Deploy to Vercel or another HTTPS host, then open in Chrome on your Pixel:

Chrome menu ⋮ → Add to Home screen → Install

Voice recognition generally requires HTTPS or localhost.
